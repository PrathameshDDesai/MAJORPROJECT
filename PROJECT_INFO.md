# 📁 UniRooms Project Information & Structure

Welcome to **UniRooms**! This document provides a comprehensive overview of the technologies, libraries, folder structures, and file responsibilities used in this application.

---

## 🛠️ Technology Stack & Dependencies

The project is built as a MVC (Model-View-Controller) full-stack web application using Node.js, Express, and MongoDB, combined with EJS templating on the frontend and Java utilities for text analysis.

### 1. Core Backend & Web Framework
*   **Node.js**: The JavaScript runtime environment.
*   **Express.js (v5.2.1)**: The core web application framework routing HTTP requests, serving pages, and processing APIs.
*   **express-session**: Standard Express session management to track authenticated user states securely across page navigations.
*   **connect-flash**: Middleware utilized to set temporary feedback notifications (flash messages) for error or success states.
*   **method-override**: Allows the use of HTTP verbs such as `PUT` and `DELETE` via traditional HTML forms (which default to only `GET` and `POST`).
*   **dotenv**: Simple environment variable manager loading variables from a `.env` file into `process.env`.

### 2. Database & Data Modeling
*   **MongoDB**: A NoSQL document database chosen for storing flexible schema documents (e.g., room listings, users, reviews).
*   **Mongoose (v9.1.1)**: MongoDB object modeling tool designed to run in an asynchronous environment. It handles schema definition, model relationship constraints, validations, and query operations.

### 3. User Authentication
*   **Passport.js**: Authentication middleware package.
*   **passport-local**: Implements standard username and password login strategies.
*   **passport-local-mongoose**: Mongoose plugin that simplifies integrating Mongoose schemas with passport-local (adds pre-configured username/password fields and password hashing automatically).
*   **passport-google-oauth20**: Allows users to log in securely with their Google accounts.

### 4. File Upload Handling
*   **Multer**: A middleware primarily used for uploading files (primarily image formats in listings forms) over `multipart/form-data`.

### 5. Java Sentiment & Content Utilities
*   **Java SE (Standard Edition)**: Programmed custom text-analysis tools (`ReviewAnalyzer`, `AnalyzerEngine`) invoked directly from Node.js runtime environment to audit reviews dynamically before storing them in MongoDB.

## ⚡ Key System Integration: Node.js & Java Interoperability

One of the unique features of the **UniRooms** repository is the interoperability between Node.js and Java:

*   **Sentiment Audit on Reviews**:
    When a user submits a review comment on a listing, Node.js (`controllers/reviews.js`) calls the Java application (`ReviewAnalyzer`) behind the scenes using Node's `child_process.execFile()`.
*   **The Command**:
    ```javascript
    execFile("java", ["-cp", javaDir, "ReviewAnalyzer", authorId, rating, commentText], ...)
    ```
*   **Java Processing**:
    *   `ReviewAnalyzer.java` parses the review arguments and passes them to `AnalyzerEngine.java`.
    *   `AnalyzerEngine` compares the comment text against built-in word matrices:
        *   **Positive Words**: `"great", "awesome", "excellent", "good", "love", "beautiful"`
        *   **Restricted/Spam Words**: `"spam", "scam", "fake", "terrible", "worst", "hate"`
    *   If the text contains too many spam words or fails checking constraints, Java prints `REJECTED` to standard output.
    *   If accepted, it prints `APPROVED`.
*   **Node.js Action**:
    *   Node captures the standard output of the Java subprocess.
    *   If stdout contains `REJECTED`, the review is discarded, and a flash message notifies the user.
    *   If stdout contains `APPROVED`, Mongoose saves the review into MongoDB.

## 🚀 Execution & Developer Reference

### Core Server Commands
*   **Development Server (Autoreload)**:
    ```bash
    npx nodemon app.js
    ```
*   **Standard Server Start**:
    ```bash
    node app.js
    ```

### Database Management Commands
*   **Re-seed database (wipes all existing listings & restores defaults)**:
    ```bash
    node init/index.js
    ```
*   **Verify DB connection & check listing geometry coordinates status**:
    ```bash
    node debug_data.js
    ```

### Compiling Java Utilities
If you edit any of the files in `java_utils/`, recompile them using:
```bash
cd java_utils
javac *.java
```
